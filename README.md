# 🧠 Сайт психолога — Лицей №23

Школьный проект на Django — сайт для онлайн-записи к педагогу-психологу.

**Рабочий инструмент:** ученики и родители выбирают свободное время и записываются на приём, психолог получает уведомление на email. Администратор через панель Django управляет расписанием, слотами и просматривает записи.

Разработан для реального использования в **МАОУ Лицей №23 г. Калининград**.

---

## Функции

- 👩‍🏫 **Каталог психологов** — фотографии, контакты, классы
- 🗓️ **Расписание слотов** — выбор свободного времени у конкретного психолога
- 📝 **Два типа приёма** — обычная консультация и обследование дошкольника (разные поля формы)
- ❌ **Отмена записи** — в один клик со страницы «Моя запись» (за 24ч до приёма — через звонок)
- 📧 **Email-уведомления** — психологу о новой записи и отмене (асинхронно, не блокирует пользователя)
- 🌙 **Тёмная тема** — переключение в шапке, сохраняется в `localStorage`
- 🔧 **Админ-панель** — управление данными, генератор расписания, удобный дашборд
- 📱 **Адаптивная вёрстка** — работает на телефонах и планшетах

---

## Административная панель

Для не-технических пользователей (психолог, секретарь):

- **Дашборд** — статистика (записи сегодня / на неделю / свободные слоты), карточки разделов с русскими подсказками
- **Записи** — поиск по ФИО/телефону, фильтр по психологу/дате/типу, колонка «Примечание» с первыми 50 символами
- **Слоты** — inline-toggle доступности, колонка «Кто записан» со ссылкой, генератор расписания в один клик
- **Психологи** — превью фото, фильтр по классам
- **Безопасно** — нет «Пользователи/Группы» (скрыты), нет массового удаления, слоты readonly в карточке записи

## Технологии

| Компонент | Технология |
|-----------|-----------|
| Backend | Python 3.12, Django 5.2 |
| База данных | SQLite (локально) / PostgreSQL (на сервере) |
| Фронтенд | Bootstrap 5.3 (CDN), data-bs-theme dark mode |
| Email | Django-smtp / threading (асинхронно) |
| Статика | WhiteNoise |
| Хостинг | Render |
