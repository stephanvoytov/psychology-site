# Сайт психолога — Лицей №23

Школьный проект — Django-сайт для онлайн-записи к педагогу-психологу.

Представляет собой рабочий инструмент: ученики и родители могут выбрать свободное время и записаться на приём, а психолог получает уведомление на email. Администратор через панель Django управляет расписанием, слотами и просматривает записи.

Разработан для реального использования в МАОУ СОШ №23 г. Калининград.

---

## Функции

- Каталог психологов с фотографиями и описанием
- Расписание свободных слотов на ближайшие дни
- Форма записи с двумя типами приёма: консультация и обследование
- Отмена записи в один клик со страницы «Моя запись»
- Email-уведомления психологу о записи и отмене
- Тёмная тема (переключение в шапке)
- Административная панель для управления данными
- Адаптивная вёрстка, работает на мобильных устройствах

---

## Технологии

Python, Django 5.2, SQLite / PostgreSQL, Gunicorn, WhiteNoise.  
Хостинг — Render.
